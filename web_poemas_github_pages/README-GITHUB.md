# Web de poemas — preparada para GitHub Pages

## Publicarla en GitHub

1. Crea un repositorio en GitHub (por ejemplo, `web-de-poemas`).
2. Descomprime este ZIP en tu ordenador.
3. Sube **el contenido** de esta carpeta al nivel principal del repositorio. `index.html` debe quedar en la raíz, no dentro de otra carpeta.
4. En el repositorio, abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Elige la rama `main` y la carpeta `/(root)`, guarda y espera a que termine la publicación.
7. Abre la URL que te muestre GitHub Pages.

Las páginas HTML y la carpeta `imagenes` deben conservarse juntas. Las rutas locales de Windows se han corregido y se ha añadido un ajuste básico para pantallas pequeñas.
